Good-natured Pest Control Optimisation

Author: Rocco Hafenstein
Capstone Project | QUT IFQ721 Data Analytics
Overview

This project optimises pest control strategies for Good-natured, a New Zealand-based company specialising in humane rodent traps to protect biodiversity. By analysing environmental and trap performance data, the project uncovers key factors influencing trap success and provides actionable insights to improve trap deployment.
Objective

To analyse historical trap data alongside environmental variables (temperature, time, geography) to:

    Identify optimal conditions for trap success.

    Evaluate trap performance across time and locations.

    Provide recommendations for improving deployment strategies.

Tools & Technologies

    Python

    Pandas, NumPy – Data cleaning & manipulation

    Matplotlib, Seaborn – Visualisation

    Datetime, Grouping/Aggregation – Time-series analysis

Key Analysis Techniques

    Filtering and cleaning raw trap data.

    Grouping by environmental factors: temperature, hour, month, season, day vs. night.

    Visualising activation frequencies using bar charts, scatter plots, and time-series graphs.

    Exploring trap success by Group ID configurations.

    Localising performance based on geographical subsets (e.g. Australian deployment).

Key Findings

    Temperature (~18°C) is optimal for trap activation.

    Rodent activity peaks in Autumn, especially in April–May.

    Highest activity is between 8 AM–2 PM.

    Groups of 2, 3, and 5 traps show higher strike numbers.

    Preliminary geographic analysis suggests location may influence success.

Recommendations

    Prioritise trap deployment during cooler months, especially Autumn.

    Focus monitoring during peak hours (8 AM–2 PM).

    Deploy traps in moderate temperature zones (~18°C) for higher efficiency.

    Explore effectiveness of smaller group configurations.

    Conduct further research into rodent behaviour to complement environmental data.
