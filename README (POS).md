Point of Sale System Analysis

Author: Rocco Hafenstein
Bootcamp Project | QUT Data Analytics
Overview

This project analyses Point of Sale (POS) data from multiple businesses to uncover patterns in profitability, popular products, and customer loyalty over time.
Objective

    Parse and analyse POS sales records (JSON format).

    Calculate annual profit, identify best-selling products, and measure customer loyalty.

    Build reusable functions for POS data extraction and insights.

Tools & Technologies

    Python

    Pandas, collections, datetime – Data manipulation & time analysis

    JSON – File parsing and nested data handling

    Functions – Custom Python functions to automate analysis

Key Analysis Techniques

    Grouped sales data by business and year.

    Calculated profit by subtracting cost from total sales.

    Identified most sold product per business/year.

    Tracked repeat customers to assess loyalty.
Key Insights

    Each business has distinct high-performing products.

    Certain years showed dips in profit, possibly tied to economic cycles.

    Repeat customer data can reveal which businesses build the most customer trust.
