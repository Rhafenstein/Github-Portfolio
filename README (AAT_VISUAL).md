Australian Air Traffic Visualisation

Author: Rocco Hafenstein
Bootcamp Project | QUT Data Analytics
Overview

This project explores trends in Australian air traffic from 1984 to 2022 using government aviation data. The goal was to identify patterns in passenger movements and visualise long-term shifts for policy, planning, and recovery strategies.
Objective

    Clean and transform historical aviation data (in JSON format).

    Visualise national and state-level passenger traffic trends.

    Identify peaks, disruptions, and recoveries (e.g., COVID-19 impact).

Tools & Technologies

    Python

    Pandas, NumPy – Data cleaning & wrangling

    Matplotlib, Seaborn – Trend and time-series visualisations

    JSON – Raw data extraction and formatting

Key Analysis Techniques

    Converted nested JSON into structured DataFrames.

    Grouped data by year and state.

    Created line plots, heatmaps, and bar charts for trends.

    Normalised passenger data for comparative analysis.

Key Insights

    Steady growth in air traffic from 1984 to 2019, followed by a sharp decline due to COVID-19.

    Queensland and New South Wales consistently lead in total passenger volume.

    Strong seasonality patterns observed in domestic vs international flows.
